This project is made as part of the EZ Labs Assignment.
It is a single-page responsive website built using React.js and CSS.
The page design is recreated from the given Figma link, and a contact form is added which connects to the provided API endpoint.

The website is fully responsive on mobile, tablet, and desktop screens.
The contact form includes proper validation — it doesn’t allow empty fields or invalid emails.
After a successful submission, it shows the message “Form Submitted” on the screen.

The background and mandala are designed to blend smoothly for a clean look,
and small UI improvements like spacing, text alignment, and hover effects are added for a better user experience.

Overall, the project focuses on design accuracy, responsiveness, and working form integration.
